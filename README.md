# 🚀 FinFlow

מערכת ניהול פיננסית חכמה מבוססת בינה מלאכותית המיועדת לעסקים קטנים ובינוניים.  
מאפשרת ניתוחים עסקיים, בניית אסטרטגיה פיננסית, עוזר אישי AI, דוחות מותאמים, ועוד.

---

## 🔧 תכונות עיקריות

- 📊 דשבורד ניתוחים בזמן אמת
- 🤖 עוזר עסקי מבוסס AI
- 📈 בניית אסטרטגיה פיננסית מותאמת אישית
- 🔐 הגנת פרטיות (GDPR + אבטחת מידע)
- 💼 היררכיית הרשאות למשתמשים
- ☁️ פריסה מלאה על Vercel עם CI/CD

## 🛠️ התקנה מקומית (למפתחים)

```bash
git clone https://github.com/razrozen/finflow-core.git
cd finflow-core
npm install
cp .env.example .env   # צור משתני סביבה
npm run dev
```

## 🚀 הפעלה מקומית

```bash
npm install
npm run dev
```

## ✅ בדיקות

```bash
npm run test
```

## 🔐 פרטיות ואבטחה

- **הגנה על API keys** - משתני סביבה מוגנים
- **סינון XSS / SQLi** - ניקוי קלט מתקדם
- **תאימות GDPR** - ניהול נתונים אחראי

## 🏗️ מבנה הפרויקט

```
src/
├── ai/                    # מודולי בינה מלאכותית
│   ├── modules/          # יועצים מתמחים
│   └── core/            # ליבת ה-AI
├── components/          # רכיבי React
├── tests/              # בדיקות מקיפות
│   ├── security/       # בדיקות אבטחה
│   ├── privacy/        # בדיקות פרטיות
│   └── ai/            # בדיקות AI
└── services/          # שירותי API
```

## 🛡️ אבטחה ובדיקות

המערכת כוללת **52 טסטים מקיפים** הכוללים:

### בדיקות אבטחה
- זיהוי והסרת XSS
- מניעת SQL Injection
- הגנה על משתני סביבה
- אבטחת AI ונתונים רגישים

### בדיקות פרטיות
- תאימות מלאה ל-GDPR
- ניהול הסכמות משתמש
- מחיקת נתונים לפי בקשה
- אנונימיזציה אוטומטית

### בדיקות AI
- בדיקת איכות תשובות
- סינון נושאים אסורים
- הגנה על נתונים אישיים
- ולידציה של המלצות עסקיות
