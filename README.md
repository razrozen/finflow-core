# FinFlow 🚀

מערכת לניהול פיננסי חכם מבוססת בינה מלאכותית וייעוץ עסקי.

## 🧩 תכונות עיקריות
- ניתוח פיננסי מבוסס AI
- יצירת אסטרטגיות מותאמות אישית
- עוזר עסקי אינטראקטיבי
- עמידות ל-GDPR ואבטחת מידע מתקדמת

## 🚀 הפעלה מקומית

```bash
npm install
npm run dev
```

## ✅ בדיקות

```bash
npm run test
```

## 🔐 פרטיות ואבטחה

- **הגנה על API keys** - משתני סביבה מוגנים
- **סינון XSS / SQLi** - ניקוי קלט מתקדם
- **תאימות GDPR** - ניהול נתונים אחראי

## 🏗️ מבנה הפרויקט

```
src/
├── ai/                    # מודולי בינה מלאכותית
│   ├── modules/          # יועצים מתמחים
│   └── core/            # ליבת ה-AI
├── components/          # רכיבי React
├── tests/              # בדיקות מקיפות
│   ├── security/       # בדיקות אבטחה
│   ├── privacy/        # בדיקות פרטיות
│   └── ai/            # בדיקות AI
└── services/          # שירותי API
```

## 🛡️ אבטחה ובדיקות

המערכת כוללת **52 טסטים מקיפים** הכוללים:

### בדיקות אבטחה
- זיהוי והסרת XSS
- מניעת SQL Injection
- הגנה על משתני סביבה
- אבטחת AI ונתונים רגישים

### בדיקות פרטיות
- תאימות מלאה ל-GDPR
- ניהול הסכמות משתמש
- מחיקת נתונים לפי בקשה
- אנונימיזציה אוטומטית

### בדיקות AI
- בדיקת איכות תשובות
- סינון נושאים אסורים
- הגנה על נתונים אישיים
- ולידציה של המלצות עסקיות
