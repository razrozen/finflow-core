# UI Components

תיקייה זו מיועדת לרכיבי UI כלליים שניתן לעשות בהם שימוש חוזר בכל האפליקציה.

## דוגמאות לרכיבים:
- Button.tsx - כפתורים
- Card.tsx - כרטיסיות
- Input.tsx - שדות קלט
- Modal.tsx - חלונות מוקפצים
- Loading.tsx - אנימציות טעינה

## שימוש:
```tsx
import Button from '../components/ui/Button';
import Card from '../components/ui/Card';
```
